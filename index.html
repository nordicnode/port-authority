§ 02

02 / About

Mega-lo-Mania is an island-conquest strategy game: grow a tribe, race through nine epochs from stone age to 2001, and conquer the island sector by sector before you get raided. 28 islands, four tribes. I played it on the Amiga 500 as a kid.

This port rebuilds it from the original binary so it runs natively on Linux — no emulator. The behaviour is recovered from the original and checked against it, so what survives is the game itself, not just a copy of the files.

03 / Status

  • [DONE]First screen running — the player-select screen draws and animates through the original’s own frame loop.
  • [DONE]Original behaviour recovered — the game’s random number generator and the commanders’ blink timing are ported and checked against the original.

§ 04

04 / Run it

You need your own original game files — the port ships none. make check verifies the port still matches the original.

Terminal
$ git clone https://github.com/nordicnode/mega-lo-mania-port
$ cd mega-lo-mania-port

# Add your own original game files
# (none are included in the repo)

$ make check        # the faithfulness gates
$ ./megalomania --run

Full details, tech notes and the dev log are in the repo: github.com/nordicnode/mega-lo-mania-port
